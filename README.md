## About Me

I'm a final-year Biochemistry and Microbiology student who enjoys the point where wet-lab work meets data. I prepare reagents, run assays and read gels — then take the raw numbers into Python to calculate results, fit curves, and turn them into something a report or a decision can be built on. I'm careful, methodical, and genuinely curious about the "why" behind a result, not just the "what."

> 🔬 *A good result is only as strong as the analysis behind it.*
